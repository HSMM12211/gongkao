# 申论训练闭环需求方案

日期：2026-05-27

## 1. 背景

当前应用已经具备素材知识库、申论演练、智能温故、字帖导出和 Skill/Agent 能力。下一阶段需要把这些能力统一到“申论训练闭环”中，解决用户在申论备考中的核心问题：不是只缺素材，而是缺少从材料输入、限时作答、批改复盘到针对性再练的完整校准系统。

本需求只覆盖申论部分，不扩展行测训练。

## 2. 产品目标

把每一次申论训练都变成下一次提分的校准数据。

核心闭环：

```text
离线资料 / 在线素材
-> 素材知识库解析入库
-> 生成真题、题目、材料、表达、评分要点
-> 申论训练闭环调用
-> 限时训练 / 考场模式 / 复盘诊断
-> 生成错因、能力画像、温故卡、字帖摘抄
-> 反哺智能温故与素材库
```

## 3. 导航与信息架构

左侧主导航只保留一个申论训练总入口，不拆成多个入口。

推荐将现有“申论演练舱”升级为：

```text
申论训练闭环
```

左侧主导航建议：

```text
工作台
专注唤醒舱
智能温故舱
申论训练闭环
字帖导出舱
素材知识库
系统设置
```

进入“申论训练闭环”后，页面内部使用二级导航承载功能：

```text
今日训练
时间感训练
复盘诊断
评论转表达
考场模式
阶段校准
```

## 4. 申论训练闭环能力模块

### 4.1 今日训练

作为申论训练闭环首页，不直接堆叠工具，而是根据用户近期弱项、训练记录和素材库资产，给出当天建议。

示例：

```text
今日建议：
你的主要问题是：对策空泛 + 时间分配不稳

建议完成：
- 1 道对策题限时训练
- 1 次错因复盘
- 10 条规范表达温故
```

### 4.2 时间感训练

训练申论作答节奏，记录用户在不同阶段的耗时。

建议拆分：

```text
读材料
标注问题
列提纲
正式作答
自查修改
```

系统需要记录：

- 每阶段耗时
- 是否超时
- 最终字数
- 是否提前完成
- 用户主要卡点

目标不是简单倒计时，而是识别用户到底是读材料慢、提纲慢、写作慢，还是自查不足。

### 4.3 复盘诊断

AI 批改后不只给分，而是结构化归类错因。

错因类型包括：

- 要点遗漏
- 材料定位错误
- 概括不准
- 对策空泛
- 逻辑层次混乱
- 表达口语化
- 字数控制失败
- 题型意识错误

系统需要形成个人错因统计，例如：

```text
本周主要问题：
对策空泛 43%
要点遗漏 28%
表达口语化 16%
```

### 4.4 评论转表达

用户导入评论文章、政策文件、热点素材后，系统拆解文章结构，转成可用于申论训练的表达资产。

输出包括：

- 规范表达
- 问题表述
- 原因分析
- 对策句
- 金句
- 主题标签
- 可练题目

该模块不以“收藏文章”为目标，而是把文章转成可写、可练、可复盘的训练单元。

### 4.5 考场模式

提供接近真实考试的全真训练环境。

能力要求：

- 全屏或沉浸式界面
- 固定倒计时
- 材料区 + 答题区
- 训练中不显示 AI 提示
- 到点自动进入复盘
- 记录完成时间、超时、字数、修改情况

考场模式可以调用素材知识库中的完整真题套卷。

### 4.6 阶段校准

沉淀用户每次训练和模考表现，形成阶段记录与能力画像。

能力维度包括：

- 阅读提取
- 归纳概括
- 综合分析
- 对策提出
- 公文格式
- 大作文立意
- 规范表达
- 时间控制

系统需要基于历史训练给出下一阶段建议，而不是只展示分数。

## 5. 离线文档入库联动

离线文档入库必须与申论训练闭环联动。用户导入资料后，不只是进入素材库保存，而是被解析为可训练资产。

支持文档类型：

- 历年申论真题 PDF
- 机构讲义
- 政策文件
- 评论文章
- 个人整理资料
- 错题复盘文档

导入时需要允许用户选择文档类型：

```text
真题套卷
单题材料
参考答案 / 评分标准
政策文件
评论文章
讲义资料
个人笔记
```

## 6. 入库后的结构化资产

离线文档解析后，需要尽量拆分为以下资产：

```text
真题套卷
材料段落
题目
参考答案
评分要点
规范表达
政策素材
热点案例
错因样本
字帖摘抄
```

所有资产都应保留来源信息，便于追溯原始文档、页码或片段。

## 7. 与训练闭环的联动方式

### 7.1 时间感训练联动

从历年真题中抽取单题或套题，直接进入限时训练。

### 7.2 复盘诊断联动

如果真题文档中包含参考答案或评分要点，AI 批改时应优先对照真实要点，而不是只做泛泛点评。

### 7.3 评论转表达联动

政策文件、评论文章、讲义资料可以被转成规范表达、问题-原因-对策素材卡。

### 7.4 考场模式联动

完整真题套卷可以一键进入全真模拟，包括材料、题目、限时、作答、批改、复盘。

### 7.5 阶段校准联动

每次真题训练结果进入用户能力画像，更新弱项、耗时、题型表现和下一阶段建议。

## 8. 模块职责边界

```text
素材知识库 = 资料加工中心
申论训练闭环 = 训练执行中心
智能温故舱 = 复盘记忆中心
字帖导出舱 = 表达沉淀中心
```

素材知识库负责导入、解析、结构化、审核和资产沉淀。

申论训练闭环负责调用资产进行限时训练、考场模拟、批改复盘和阶段校准。

智能温故舱负责复习错因、规范表达、素材卡和高频弱项。

字帖导出舱负责把高质量表达、金句和规范句转成临摹内容。

## 9. 核心用户流程

### 9.1 历年真题训练流程

```text
导入历年真题 PDF
-> 选择文档类型：真题套卷
-> 系统解析材料、题目、参考答案、评分要点
-> 用户确认入库
-> 在申论训练闭环中选择该套真题
-> 进入考场模式或单题时间感训练
-> 作答后 AI 对照评分要点批改
-> 生成错因、能力画像、温故卡
```

### 9.2 评论文章表达训练流程

```text
导入评论文章 / 政策文章
-> 选择文档类型：评论文章 / 政策文件
-> 系统提取规范表达、问题、原因、对策
-> 生成表达卡和练习题
-> 用户进入评论转表达训练
-> 写作后 AI 诊断表达迁移能力
-> 优秀表达进入温故和字帖
```

### 9.3 错因复盘流程

```text
完成一次申论作答
-> AI 批改并归类错因
-> 错因进入个人统计
-> 系统推荐下一次训练任务
-> 相关表达和知识点进入温故
```

## 10. 成功标准

第一阶段可验证成功标准：

- 用户能从素材知识库导入一份离线申论真题资料。
- 系统能把资料拆成至少“材料 + 题目 + 参考答案/评分要点”。
- 用户能从申论训练闭环中调用该真题进行训练。
- 训练结束后能生成结构化批改结果和错因标签。
- 错因能进入阶段校准统计。
- 优质表达能进入智能温故或字帖导出。

## 11. 暂不纳入范围

- 不做行测训练。
- 不做公开题库爬虫。
- 不直接追求自动判分绝对准确，优先做结构化诊断和错因校准。
- 不把 5 个能力模块拆成左侧 5 个入口。
- 不让离线文档只停留在“文件收藏”层面，必须转成训练资产。
