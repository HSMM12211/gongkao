# Quickstart: Materials Chat Streaming UI

1. Start the app with `npm run dev` or the Tauri desktop dev command.
2. Open `/materials`.
3. Type a prompt such as `@Skill:热点采集器 采集数字乡村热点，生成金句和对策题。`
4. Click the round send button.
5. Verify a user message appears immediately.
6. Verify an assistant message appears and updates with Agent run events.
7. Upload a PDF and start整理.
8. Verify file chips appear with the user message and parsing/Agent events appear in the assistant message.
9. Switch to Skill 管理, then return to 素材工作台.
10. Verify the recent conversation remains visible.
11. When the run completes, verify the assistant message shows Inbox 待审核 rather than claiming direct import.
