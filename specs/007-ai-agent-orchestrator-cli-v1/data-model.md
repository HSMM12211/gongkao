# Data Model: AI Agent Orchestrator CLI v1

## AgentTaskPlan

Represents the user-facing plan for a single Agent run.

Fields:
- `runGoal`: concise user-facing goal.
- `skill`: selected Skill id, name, trust, source, and permissions.
- `context`: source title, source type, original size, provided size, mode, and warnings.
- `toolRoute`: primary tool, fallback tools, reasons, warnings, and permissions.
- `memory`: bounded local memory summary and warnings.
- `workflow`: single-agent or planned planner/executor/evaluator mode.
- `expectedArtifacts`: expected output files and review destination.
- `reviewRequired`: always true for study assets generated by Agent.

Validation:
- Must include a Skill id and run goal.
- Must include at least one expected artifact.
- Must explicitly state whether review is required.

## AgentRunEvidence

Durable summary of what happened during a run.

Fields:
- `runId`
- `plan`
- `events`
- `artifacts`
- `diagnostics`
- `validation`
- `review`
- `workspacePath`

Validation:
- Terminal runs must have one terminal status: waiting review, completed, failed, or cancelled.
- Diagnostic messages must not automatically imply failure.

## ContextSummary

Bounded source context exposed to the Agent and user.

Fields:
- `mode`: full source, snippets, or map.
- `originalSourceChars`
- `providedSourceChars`
- `estimatedSections`
- `snippets`
- `warnings`

Validation:
- If provided size is smaller than original size, warnings must include a partial coverage message.

## MemorySummary

Bounded local learning-state summary.

Fields:
- `recentRuns`
- `assets`
- `pendingInbox`
- `learningGaps`
- `warnings`

Validation:
- Must not include complete raw user history.
- Must be safe to include in prompt and UI trace.

## ValidationSummary

Unified structure and business gate summary.

Fields:
- `structureOk`
- `businessOk`
- `errors`
- `warnings`
- `confidence`
- `reviewRecommendation`

Validation:
- If errors exist, the candidate cannot be imported.
- If warnings exist, the review recommendation should require review.

## ReviewCandidate

Agent-generated candidate waiting for confirmation.

Fields:
- `draftId`
- `runId`
- `status`
- `summary`
- `counts`
- `warnings`

Validation:
- Formal import requires a user action.
